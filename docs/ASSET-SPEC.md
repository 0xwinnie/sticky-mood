# 资产规格 — 猫插画 / 图标 / 字体

给设计者和字体采购用的规格。所有尺寸都是**设备上的实际像素**（逻辑画布竖屏 480×800，1-bit 黑白）。
尺寸由设计稿 `docs/design/mockup-8pages.png` 的比例推得（稿中屏宽约 280 px 对应 480 逻辑像素，
比例 ≈1.7），都是可调值——改 `main/ui/layout.h` 里的常量即可，不用重新出图。

## 0. 三条硬规则

1. **屏是 1-bit。** 只有纯黑和纯白，没有灰、没有半透明。交付物必须是二值图。
2. **线宽在目标尺寸下 ≥ 2 px。** 1 px 的线在墨水屏上会断线、发虚。
3. **选中态/反白不用出图。** 代码按位取反实现，设计师只出"黑线白底"一版。

## 1. 交付格式（二选一）

| 方式 | 要求 | 适用 |
|---|---|---|
| **A. 矢量源文件（推荐）** | SVG / AI / Figma 导出。我来栅格化 + 二值化 | 全部资产。图标要在多个尺寸复用，矢量最合适 |

## 4. 字体

### 拉丁字体：✅ 已到位

用户已提供三款，都在 `assets/fonts/`，均 **SIL OFL 1.1**（允许嵌入固件 + 再分发），
授权文件同目录保留：

| 字体 | 特点 | 倾向用途 |
|---|---|---|
| Manrope | x-height 高、笔画均匀，1-bit 小字号最稳 | 正文 / 笔记卡片 |
| Plus Jakarta Sans | 略宽、更中性 | 正文备选 |
| Playpen Sans | 圆润手写感，最贴合"可爱"基调；笔画偏粗 | 标题 / 心情词，14–16 px 易糊 |

三款都是可变字重（`*VariableFont_wght.ttf`），需要具体字重时用 fontTools
`varLib.instancer` 实例化，不必再补静态字重。最终搭配等中文字体定了再看整体观感。

### 中文字体：✅ 已定为思源柔黑 GenSenRounded2 TC

用户最初点名**苹方 PingFang SC**，这条路走不通：苹方是 Apple 的专有字体，
授权只覆盖 Apple 自家设备上的显示，**不允许提取字形、做成点阵字库嵌进固件再分发**。
而本项目的固件会发给 Seeed 借测，未来还可能发布到 Playground Registry（MIT 开源），
两次都构成分发。

最终选定 **GenSenRounded2 TC（思源柔黑，v2.100，SIL OFL 1.1）**，已入库
`assets/fonts/gensen-rounded/`（GB2312 子集 M/B 两个字重 + 授权文件 + 1-bit 实测预览）。
要点：

- 上游只发 JP/PJP/TC/TW 区域包、**没有 SC 包**；但实测 TC 版 cmap 含 35,382 字形，
  简体码位齐全，本项目全部 UI 字符串零缺字（实测表见该目录 README）。
  区域笔形差异只影响「直/骨/角」这类共享码位，属可接受的美学差异。
- 1-bit 小字号实测：16/18 px 下 **M 字重最稳**（R 偏细、B 过粗），故正文用 M、
  标题/问候语用 B。
- 许可红线不变：必须允许"嵌入固件 + 再分发"，OFL 或明确"免费商用"才行；
  "仅限个人学习"的字体、以及苹方这类平台专有字体都不能用。

### 我会怎么处理

- 栅格化成点阵子集烧进 flash。
- 字号档位：**14 / 16 / 18 / 20 / 24 / 28 px**。
- 中文出 **16 / 18 / 24 / 28 px** 四档：16=笔记正文/卡片，18=按钮/列表项/卡片值，
  24=页标题，28=问候语（页标题和问候语是中文，原计划只出 16/18 会缺字）。
  GB2312 子集四档合计 ≈ 1.6 MB；拉丁出全部 6 档（ASCII 子集，< 50 KB）。
  这是刻意的容量取舍；将来要更多中文字号就改放 SD 卡。
- 14/20 px 两档仅拉丁用（状态栏日期/提示语、次级标题）。
- 字重映射（2026-09-15 定）：**标题档加粗**——拉丁 24/28 从 Manrope 可变字体取
  wght=700，14–20 保持 regular；中文 24/28 用 B、16/18 用 M。页面代码只认
  `layout::Face`，字重变化不需要改渲染代码。
