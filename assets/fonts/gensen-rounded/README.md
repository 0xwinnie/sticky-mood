# GenSenRounded2 TC（思源柔黑）— 中文点阵字源

- 上游：https://github.com/ButTaiwan/gensen-font ，release **v2.100**
- 许可：**SIL OFL 1.1**（见同目录 `SIL_Open_Font_License_1.1.txt`），允许嵌入固件 + 再分发
- 取用方式：从 release 的 `GenSenRounded2TC-otf.zip` 取 R/M/B 三个全量 OTF，
  用 `fontTools.subset` 裁到 **GB2312（7544 码位）** 后入库；本目录只保留子集版，
  全量 OTF 每个 15 MB，不进仓库。需要重新裁字集时从上游 release 重新下载即可。

## 为什么是 TC 而不是 SC

上游只发布 JP / PJP / TC / TW 四个区域版，**没有 SC 包**。但实测 TC 版的 cmap
含 35,382 个字形，简体码位齐全（国/东/关/说/长 等与繁体码位并存），
本项目全部 UI 字符串（见下）零缺字。区域字形差异只影响「直/骨/角」这类共享码位
的笔形细节，对心情记录 app 是可接受的美学差异，不是正确性问题。

覆盖实测（`GenSenRounded2TC-R.otf` 全量版）：

| 测试串 | 结果 |
|---|---|
| 今天感觉如何能量需要记一笔最近三个月心情笔记语音正在聆听已保存专注创作休息运动连接 | 39 字全覆盖 |
| 上午下午晚上周一二三四五六日年月时分电量低满 | 20 字全覆盖 |
| 简繁差异字（国与发对关让说话见东车马鱼鸟门长书记听声音应该体验记录时间情绪） | 30 字全覆盖 |

## 保留字重

| 文件 | 用途 |
|---|---|
| `GenSenRounded2TC-M-gb2312.otf` | 正文 / 卡片 16、18 px（1-bit 下 M 比 R 稳，见预览图） |
| `GenSenRounded2TC-B-gb2312.otf` | 页标题 / 问候语 24、28 px |

`preview-1bit-14-16-18.png` 是 R/M/B 三档在 14/16/18 px 二值化后的实测渲染，
选 M 作正文的依据就在图里：R 偏细、B 过粗。

## 点阵档位

中文出 **16 / 18 / 24 / 28 px** 四档（比 ASSET-SPEC 原计划多了 24/28：
页标题和问候语是中文，只出 16/18 会缺字）。GB2312 子集四档点阵合计约 1.6 MB，
在 32 MB flash 里仍可忽略。
